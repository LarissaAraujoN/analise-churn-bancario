# Análise de Churn bancário
Projeto de análise exploratória de dados para identificar padrões de cancelamento de clientes em um banco utilizando Python, Pandas e Plotly.

---

## 🎯 Objetivo do Projeto

Analisar a base de clientes do banco para entender quais perfis e comportamentos de clientes apresentam a maior taxa de cancelamento. 

---

## 🛠️ Tecnologias Utilizadas

* **Python 3**
* **Pandas**: Leitura, tratamento de nulos (`dropna`) e estatística descritiva (`describe`).
* **Plotly Express**: Criação de histogramas interativos para análise gráfica.

---

## 📈 Principais Insights:

   * Clientes que entram em contato de até 2 vezes ao ano têm uma taxa de cancelamento quase nula.
   * A partir do 4º contato, a proporção de cancelamentos cresce drasticamente.
   * Clientes com 5 ou 6 contatos cancelam quase em sua totalidade indicando que pode haver um problema recorrente que não foi resolvido no primeiro suporte.
